## 社区老年食堂订餐系统

基于SpringBoot+Vue的社区老年食堂订餐系统，系统包含三种角色：管理员、员工、用户，分为前台和后台两大模块。

### 管理员
- 个人中心：管理个人信息
- 菜品管理：创建、修改和删除菜品信息
- 订单管理：查看和处理订单
- 供应商管理：管理食堂的供应商信息
- 员工管理：管理食堂的员工信息
- 用户管理：管理用户的信息和权限
- 公告信息管理：发布和管理公告信息
- 论坛管理：管理论坛中的帖子和评论
- 轮播图管理：管理首页的轮播图信息

### 用户
- 菜品浏览：分类展示、关键词搜索
- 菜品收藏：收藏喜欢的菜品
- 在线订餐：加入购物车、提交订单
- 订单查询：查看订单进度
- 论坛交流：发帖和评论
- 个人中心：管理个人信息

### 员工
- 菜品管理：创建、修改和删除菜品信息
- 供应商管理：管理食堂的供应商信息
- 公告信息管理：发布和管理公告信息

### 前台页面
- 菜品：查看和点餐菜品
- 论坛：用户交流分享
- 公告信息：查看发布的公告
- 食堂介绍：展示食堂的介绍和特色
- 联系我们：提供食堂的联系方式

## 技术栈
- 后端：SpringBoot 2.2.2 + MyBatis Plus + MySQL
- 前端：Vue2 + ElementUI（管理后台）、HTML + CSS + JavaScript（前台页面）
- 工具：Maven、JDK 1.8

## 运行环境
- JDK 1.8及以上
- MySQL 5.7及以上
- Maven 3.0及以上

## 快速启动

1. 创建数据库并导入 `db/init.sql`
2. 修改 `src/main/resources/application.yml` 中的数据库连接配置
3. 运行 `mvn spring-boot:run`
4. 访问前台：http://localhost:8080/canyinguanli/front/index.html
5. 访问后台：http://localhost:8080/canyinguanli/admin/dist/index.html
